# EVE-RAG — Multimodal Context Verification

Research into out-of-context image-caption detection through complementary evidence streams and learned fusion.

## Architecture

- **Stream A:** named-entity extraction, visual grounding and entity consistency.
- **Stream B:** CLIP feature extraction with LoRA adaptation.
- **Stream C:** evidence retrieval and stance scoring.
- **Fusion:** gated stream-attention fusion, classifier and ablation alternatives.

The implementation of `GatedStreamAttentionFusion` is in `src/models/fusion.py`. That file is generated by `notebooks/05_fusion/fusion_module.ipynb`; edit the notebook when changing its source.

## Getting started

```bash
python -m venv .venv
# Activate the virtual environment for your operating system.
python -m pip install -r requirements.txt
python -m spacy download en_core_web_trf
python -m jupyter lab
```

Obtain the datasets and model assets referenced by the setup notebooks before running experiments. GPU memory and access requirements vary by notebook; installation alone does not reproduce the full pipeline.

## Notebook order

1. `notebooks/01_setup/`: environment, data preparation and exploration.
2. `notebooks/02_stream_a/`: entity verification.
3. `notebooks/03_stream_b/`: CLIP and LoRA features.
4. `notebooks/04_stream_c/`: evidence and stance.
5. `notebooks/05_fusion/`: fusion and baselines.
6. `notebooks/07_eval/`: cross-dataset evaluation and ablations.
7. `notebooks/08_paper/`: tables and figures.

## Supporting files

`configs/` holds experiments; `src/utils/paths.py` centralizes paths; `scripts/` contains dataset helpers. `finalized_outputs/` preserves figures, diagrams and report artifacts. Large datasets, model caches and experiments remain ignored. Local editor and assistant settings are excluded from version control.

## Research status

The repository uses the EVE-RAG name. Do not infer an accepted publication or equate this implementation with a differently titled manuscript without checking its corresponding paper/version.
